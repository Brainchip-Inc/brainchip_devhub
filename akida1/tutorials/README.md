# Akida 1 Tutorials

Self-contained notebooks that explain how the Akida 1 technology works in
depth. Each tutorial is a single notebook in this folder; it builds on the
[model zoo](../model_zoo) examples (reusing their model, data and training
code rather than copying it), so run it from this folder, or use the Colab
link, which sets everything up.
