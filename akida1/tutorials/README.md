# Akida 1 Tutorials

Notebooks that explain how the Akida 1 technology works in depth. Each tutorial has its
own folder. Where a tutorial needs a model or data, it reuses a [model zoo](../model_zoo)
example's rather than copying them, so run it from its own folder.

| Tutorial | Notebook | Needs |
| --- | --- | --- |
| Sparsity in Akida hardware: how a layer's time and energy follow the events it receives, measured on a hand-built layer and on Visual Wake Words | [sparsity_in_hardware_notebook.ipynb](sparsity_in_hardware/sparsity_in_hardware_notebook.ipynb) | An Akida 1 device (AKD1500 for energy) |

The planned series is listed in the [Akida 1 README](../README.md#tutorials).
